# Create Package Ponderer pack

These JSON files use the [Ponderer](https://github.com/Nobodiiiii/Ponderer) scene DSL.

The same files are loaded at runtime from `assets/createpackage/ponderer/` so holding W works without installing Ponderer.

To edit them in-game with Ponderer:

1. Zip `pack.json` and the `scripts/` folder.
2. Drop the zip into `.minecraft/resourcepacks/` or import it from the Ponderer menu.
3. Copy the edited JSON back into `assets/createpackage/ponderer/`.
