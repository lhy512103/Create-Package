# Extended Kinetic Pattern Provider

<ItemImage id="extended_kinetic_pattern_provider" scale="6" />

The Extended Kinetic Pattern Provider is a high-capacity version of the <ItemLink id="kinetic_pattern_provider" />. It uses the same machine supply, output recovery, smart doubling, and parallel-machine logic, but provides paged **9×4 (36-slot)** pattern storage.

## Pattern pages

* **1 page** is enabled by default; server configuration can select 1–9 pages.
* Use the AE2 left-toolbar arrow buttons to change pages.
* Changing pages only switches the visible slots. Patterns are never moved, copied, or reordered.
* Shift quick-move and direct slot interaction only affect the current page.

If an administrator reduces the configured page count, occupied higher pages remain accessible and their patterns are not removed. A retained page disappears only after all of its patterns have been taken out.

## Usage

Connect it to the ME network, wrench-set the target side, and insert AE2 processing patterns as with the normal provider. See [Kinetic Pattern Provider](kinetic-pattern-provider.md) for Parallel Cards, Machine Linker setup, smart doubling, supported machines, and output recovery requirements.

## Crafting

Made through sequenced assembly from a Kinetic Pattern Provider. Each of four loops performs four pressing steps, deploys one consumed Polished Rose Quartz, deploys one reusable Rose Quartz, and finishes with mechanical cutting.
