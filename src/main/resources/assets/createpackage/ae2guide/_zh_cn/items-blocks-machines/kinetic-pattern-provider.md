# 动力样板供应器

<ItemImage id="kinetic_pattern_provider" scale="6" />

面向单台 Create 机器（或并行同类型机器）的 AE2 样板供应器，适合不需要完整序列组装路线的配方。

接入 ME 网络，用扳手设定目标侧，放入普通 AE2 <ItemLink id="ae2:processing_pattern" />。默认只使用正面机器。

## 并行机器

安装 <ItemLink id="parallel_card" /> 后，用 <ItemLink id="machine_linker" /> 选中供应器，再链接与正面目标同类型的机器。

* 0 张：仅正面机器
* 1 张：最多 16 台
* 2 张：最多 32 台
* 3 张：最多 48 台
* 4 张：最多 64 台

新作业优先发往空闲的已链接机器。

## 特殊机器的目标与出口

### 粉碎轮

供应器须指向两轮间自动生成的 `create:crushing_wheel_controller`，不是轮子本体。两轮同轴、相隔一格、反向转动，并向正确方向卷入物品。本例向下处理时，回收料盘或传送带在**中间处理格正下方**。

这个控制器不可见，也没有普通黑色选框。放供应器时可用临时支撑定位，再用扳手设定目标面；新增并行轮组时，在其处理格后方放可见参照块，从前方瞄准参照块，让射线先命中处理格。用 F3 确认目标 ID 后，持已选中供应器的链接器右键，成功后拆参照块。点击轮子不会自动转成控制器。

### 动力合成器

把供应器紧贴一格合成器，设单一目标面，面向该格。合成器须同朝向、同平面、上下左右连通，格数足以容纳真实配方。动力通过相邻齿轮啮合传入，不能把电机直接贴合成器背面当成轴连接。

使用 **AE 处理样板**，准确填写一份配方总材料和实际产量；不要用普通 AE 合成样板。当前适配会从配方恢复大网格，并在任务通过规划后安排箭头、合并所需输入组和供料，无需 G 检测或先手动扳完全部箭头。材料格应清空旧料并去掉盖板。

成品须能沿墙平面内的箭头送进紧邻箱子、料盘或供应器。供应器在墙边且处于同平面时可直接收品；仅贴在墙正面或背面时，另配同平面直邻的出口容器。该出口不用再挨着供应器。

并行时每套独立组只链接一格代表，正面组不用重复加。不要用批量工具把同一面墙每格都当一套机器；当前链接按方块坐标计数，同一实际作业链不会因此变成多条产线。各组留空气分隔，并提供独立出口。

### 动力锯与工作位

动力锯须朝上且有转速；出料在同高度邻格，方向随轴向与转向变化。反转后要把可回收料盘或传送带放到新出口。供应器会按样板主产物设锯过滤器。

搅拌机必须在下方两格放工作盆，物品、流体和回收都经该盆；还要满足实际转速与加热要求。压力机下方两格可放盆做盆配方，或放料盘/传送带做单物品压制。注液器的物品工位也在下方两格，流体直接进注液器，自身无需旋转动力。绑定时均点机器本体。

## FTB Ultimine 批量操作

安装 FTB Ultimine 后，本模组自动启用链接器联动；操作时始终手持 <ItemLink id="machine_linker" />。

1. 先松开 Ultimine 激活键与潜行键，右键供应器选定宿主，并确保目标面已指向有效机器。
2. 按住 Ultimine 激活键（默认反引号，可在控制设置改）。通常再按潜行键配合滚轮选择形状；若激活键本身设为 Shift，形状菜单使用 Ctrl。以预览覆盖的范围为准。
3. 选好范围后**松开潜行键，继续按住 Ultimine 激活键**，右键选区内机器，批量添加同类链接。
4. **保留潜行键**并按住 Ultimine 激活键，再右键机器，则批量解绑。只删链接，不拆方块。
5. 松开 Ultimine 激活键后，潜行右键供应器会清空全部额外链接并解除工具选择。

只处理已加载、与点击方块注册 ID 相同且符合正面机器类型的目标；选区受 FTB 配置上限约束，可分批处理。无卡能记链接，但仍只用正面机器。没有预览或动作时检查键位冲突、饥饿值、形状与模组是否安装。动力合成器请每个独立组只选一个代表，避免把同一面墙扫成重复候选。

## 支持目标

* **机械手**：加工物送工作位，施加物进机械手。若施加物不消耗且已预先放入机械手，样板可以省略该施加物。
* **注液器**：物品送工作位，流体进注液器
* **动力冲压机**：料盘/传送带模式，或下方工作盆模式
* **动力搅拌机**：工作盆配方（物品 + 流体）
* **动力锯**：按主产物物品设置过滤，从固定输出侧回收
* **石磨**：从石磨自身库存直接回收，无需额外出口料盘
* **粉碎轮**：对准轮间控制器，从其实际出口的可接收料盘或传送带回收
* **动力合成器**：按真实配方自动规划连通组，从有效平面出口回收
* **机械动力：附魔工业**：动力砂轮需放在砂轮分液池上。对准砂轮或分液池均可；产物从分液池弹出侧回收（传送带/料盘，或掉落物）。砂轮与分液池必须反向旋转。
* **CreateMoreMachines**：按注册 ID 后缀识别同角色机器，仍用标准物品/流体能力
* **Create Crafts & Additions**：轧机使用内部库存；朝上的特斯拉线圈可处理其下方两格处置物台或传送带上的物品
* **Create Diesel Generators**：工作盆盖向正下方工作盆供料并回收；大型发酵槽通过多方块能力接收物品与流体混合输入

蒸馏槽目前会被识别但暂不执行：一次加工会把不同流体产物写入不同高度的槽体，而供应器作业目前只有一个可回收输出位置。

主产物可以是物品 **或流体**。流体产物与副产物会从输出位置的流体容器回收。

## 智能翻倍

开启后会把相同样板推送合并成更大批量，批量大小按目标**空余**罐/槽容量计算。搅拌机 / 工作盆可按空机容量预收样板，整批补满而不是 1B 慢发；目标满时每 tick 重试，回收产物后立刻唤醒合成。

## 回收注意

动力锯和粉碎控制器的出口需要能接收弹出物品并提供物品库存的传送带或料盘；任意箱子、普通地面不能替代。石磨则直接从自身库存回收。动力合成器使用已规划的平面直邻出口，可为箱子、料盘或供应器。护目镜 / Jade 显示状态、作业、智能翻倍与最近失败详情。
