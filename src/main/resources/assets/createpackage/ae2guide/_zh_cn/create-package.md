# Create Package

Create Package 把 AE2 自动合成接到真实 Create 机器上，不依赖世界扫描、mixin 或反射。

**封包分发器** 用于序列组装流水线；**动力样板供应器** 用于单机（或同类型并行）处理。机械路线工具则把 AE2 样板转成带路线的机械封包样板，供高级封包分发器使用。

手持 AE2 指南并对准本模组物品/方块按 **G** 可打开对应页面。
