# Create Package

Create Package bridges AE2 autocrafting to real Create machines without world scanning, mixins, or reflection.

Use **Package Distributors** for sequenced-assembly lines, and the **Kinetic Pattern Provider** for single-machine (or parallel same-type) processing. Mechanical route tools convert AE2 patterns into route-bearing patterns for Advanced Package Distributors.

Hold an AE2 guide and press **G** over any Create Package item/block to open its page.
